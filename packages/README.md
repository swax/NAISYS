# Shared Packages

This directory contains shared packages used across the NAISYS monorepo.

## Packages

- **[@naisys/common](./common/README.md)** - Common utilities and constants
- **[@naisys/common-browser](./common-browser/README.md)** - Shared React/Mantine components and utilities for client apps
- **[@naisys/common-node](./common-node/README.md)** - Node-only utilities
- **[@naisys/hub-database](./hub-database/README.md)** - Hub database schema and Prisma client
- **[@naisys/hub-protocol](./hub-protocol/README.md)** - Protocol types and schemas for Hub communication
- **[@naisys/supervisor-database](./supervisor-database/README.md)** - Supervisor database schema and Prisma client

## Usage

These packages are internal to the monorepo and consumed by the applications in `apps/`.

For more information, see the [main README](../README.md).
